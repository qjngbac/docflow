# DocFlow 前端图片资源文档

本文档包含所有需要生成的图片资源，每张图片都有详细的中文生成提示词。

---

## 1. 登录页背景图

**文件名**：`login-bg.jpg`
**用途**：登录页面的背景渐变图
**尺寸**：1920×1080

**提示词**：
```
一张现代简约风格的抽象渐变背景图，主色调为深蓝色到紫色的渐变，背景中有轻微的几何线条和光晕效果，整体感觉科技感十足但不花哨，适合作为登录页面的背景。画面中央区域颜色较深，便于放置白色登录卡片。风格：扁平化设计，低调优雅，不喧宾夺主。
```
