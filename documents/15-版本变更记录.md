# 云笺 DocFlow 版本变更记录

## 当前版本 1.0.0

### 已实现

- Spring Boot 3 + Vue 3 的账号、文档、文件夹、权限和分享基础业务。
- Yjs/Hocuspocus CRDT 实时协作、Awareness、IndexedDB 离线恢复。
- MySQL 增量、幂等去重、当前与多代 checkpoint、历史恢复。
- Refresh Token 轮换、设备会话、闲置退出、保持登录和强制撤销。
- 富文本、Markdown、页面设置、单/双页、表格、公式、脚注、文献和批注。
- DOC/DOCX/Markdown/TXT 导入，DOCX/PDF/HTML/Markdown/TXT 导出。
- 附件列表、分片上传、标签、收藏、模板、通知和回收站保留期限。
- 问题反馈、截图、管理员回复和站内通知。
- 管理后台：用户、封禁、角色、设备、反馈、定向系统提示、系统模板、日志和状态。
- 管理员可按全部用户、完整用户名或注册时间范围发送提示；用户在工作区顶部查看并关闭。
- 登录失败验证码与临时锁定、账号/IP 限流、可信代理和 IP 黑名单。
- 可选安全 Cookie/CSRF、分享密码 BCrypt、签名文件 URL、ClamAV 和生产安全响应头。
- Nginx/WAF 示例以及依赖、代码、密钥和测试环境 DAST 自动扫描流程。

### 重要修复

- 修复新建 CRDT 文档所有者被误判为无权限。
- 修复协作更新未持久化、物化正文和更新时间不变化。
- 修复 Spring Security、JWT Filter 和 PasswordEncoder 的循环依赖。
- 修复分页横向扩展、双页全横排、页边距遮挡、长表格跨页和滚动卡顿。
- 修复管理后台返回普通文档导航无响应。
- 统一危险操作为项目居中对话框，统一前端中文错误提示。
- 修复协作恢复点、历史回滚与自动压缩全部失败：`trimHistory()` 把 `LIMIT` 写成绑定参数，MySQL 预处理协议不接受该写法（`ER_WRONG_ARGUMENTS`），而它是 `checkpoint()` 的最后一步，导致整笔事务回滚。改为拼接整型上限（取值已收敛为 2–100）。
- 修复文档导出接口恒返回 401：导出控制器返回 `Callable`，ASYNC 派发时认证过滤器默认不执行，Spring Security 判定为未认证，前端续期失败即退出登录。现让令牌校验覆盖异步派发。
- 修复导出失败会下载到"假文件"：业务错误按项目约定以 HTTP 200 + 业务错误码返回，而导出请求用 `responseType: 'blob'`，前端会把 JSON 当文件保存。现于响应拦截器识别 Blob 中的 JSON 并按错误抛出。
- 修复协作时视口被强制拽走：`y-tiptap` 应用远端更新的事务带 `scrollIntoView`，ProseMirror 会把视口滚回本地选区，表现为"对方一编辑，我的视图跳到固定位置、光标丢失"。现在只有在本地输入/本地跳转后的短时间窗内才允许该滚动。
- 修复刷新令牌续期失败即被登出：限流 429、5xx 与网络抖动不再清空登录态；只有服务端明确判定会话失效（HTTP 401）才退出。
- 修复 `@hocuspocus/server` 4.x 实例 API 误用：`documents`、`closeConnections`、`unloadDocument` 位于 Hocuspocus 实例（`server.hocuspocus`）而非外层包装对象，此前导致删除文档后关闭连接、版本回滚替换正文失败。
- 修复多条提示完全重叠：提示改为同一容器内纵向排列，最多同时显示 4 条。
- 修复批注面板筛选下拉文字被裁、协作者表单三个控件高矮不一。
- 修复双页并排显示时内容被推向右侧、右页被裁切：容器的水平留白不再按单页宽度计算，居中交由纸张自身处理。
- 修复协作恢复点面板权限判断：创建恢复点与历史回滚要求文档所有者或被授予 ADMIN 权限。

### 变更（行为变化）

- **删除文件夹改为"内容上提"语义**：删除时把其中文档与直接子文件夹移动到**最近的未删除祖先**（没有则落到根），只隐藏该文件夹本身。此前只软删文件夹、会留下指向已删除文件夹的悬空引用（子文件夹在侧栏被当作孤儿提升到顶层，文档不再属于任何可见文件夹）。
- 删除文件夹前会显示影响范围（N 个文档 / M 个子文件夹）。
- **失去写权限或被移出协作者时，会清理该文档的浏览器本地副本**（IndexedDB 离线镜像），避免"已被服务端拒绝的编辑"日后被合并回服务端。
- 协作者权限变更、文档移入回收站后，连接会被断开并在重连时重新确认权限；文档页新增「重新同步」按钮（重新确认权限、重连协作、刷新批注与协作者）。
- **分享页支持分页排版**：HTML 文档改用只读的分页渲染器（不建立协作连接、不写本地副本），按文档自身的纸张与页边距渲染；Markdown 分享沿用纸张样式。
- 登录页在登录态被动失效时会提示「登录已过期，请重新登录」。

### 安全

- 协作服务固定监听回环地址：`address = ${CRDT_HOST:127.0.0.1}`（`@hocuspocus/server` 的 `address` 默认值是 `0.0.0.0`，不设置会暴露所有网卡）。
- 修复 Redis 密码不生效：`@hocuspocus/extension-redis` 4.x 只读取配置里的 `options` 并原样传给 ioredis（`new RedisClient(port, host, options)`），顶层写 `password` 会被静默忽略；带认证的 Redis 此前无法连接。
- 异步（`Callable`）接口的鉴权已覆盖 ASYNC 派发，避免认证上下文丢失导致的 401。

### 数据库变化

- 当前全新建库为 23 张正式表。
- 最近增加 `user_session`、`user_feedback`、`feedback_image` 及用户系统角色/封禁字段。
- `upgrade_20260809_admin_message_notifications.sql` 为 `user_notification.type` 增加 `FEEDBACK_UPDATED` 和 `ADMIN_MESSAGE`。
- 已有数据库执行对应日期升级脚本；全新数据库只执行 `schema.sql`。
- **本次修复不涉及任何表结构变更**，升级时不需要执行迁移脚本。
- 可选数据修复：此前删除文件夹曾留下"`folder_id`/`parent_id` 指向已删除文件夹"的记录，若需彻底理顺可执行
  `UPDATE document d LEFT JOIN folder f ON f.id = d.folder_id SET d.folder_id = 0 WHERE d.folder_id > 0 AND (f.id IS NULL OR f.is_deleted = 1);`
  以及 `folder` 表同形状的 `parent_id` 归零语句；两表都建议先备份。

### 已知限制

- 实时分页不是完整 Word 排版引擎；复杂跨行表格和超高不可分块有边界。
- DOCX/PDF 对复杂字体、SmartArt、矢量图和任意 MathML 不保证无损。
- 文件仍以本地目录为主，多节点生产应迁移对象存储。
- 前端 E2E、真实双节点集成、容量压测和完整可观测性仍需补齐。
- 安全 Cookie、ClamAV、匿名文件关闭和 WAF 需要在生产外部配置中显式开启。
- 尚未由专业安全人员执行真实渗透测试和修复复测。
- 版本对比基于**纯文本行级差异**，因此不显示批注标记、公式等富文本标记；版本快照只保存正文，批注正文属于独立协作数据、不随版本快照保存（预览可显示批注范围高亮）。
- 分享页为只读渲染：支持分页排版与批注范围高亮，但不提供批注列表与协同编辑；分享响应不包含批注正文。
- 协作视口的稳定性依赖"本地意图"时间窗（400 毫秒）判定，极端情况下（空闲后首次输入且光标不在视野内）可能不会自动把光标滚入视口。
- 实时分页仍不是完整 Word 排版引擎：超高不可分块、极端跨页表格存在边界。
- 前端 E2E、真实双节点集成、容量压测与完整可观测性仍需补齐。
