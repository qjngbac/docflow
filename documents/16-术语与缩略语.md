# 云笺 DocFlow 术语与缩略语

| 术语 | 含义 |
| --- | --- |
| CRDT | Conflict-free Replicated Data Type，可并发、离线合并并最终收敛的数据类型 |
| Yjs | 项目采用的成熟 CRDT 实现 |
| Y.Doc | Yjs 的协作文档容器 |
| Hocuspocus | 基于 Yjs 的协作服务器和 Provider 生态 |
| Awareness | 在线用户、光标和选区等临时协作状态，不作为正文持久化 |
| Update | Yjs 二进制增量，可交换、可幂等合并 |
| State Vector | 描述客户端已拥有 Yjs 状态的向量，用于只同步缺失更新 |
| Checkpoint | 某时刻完整 Y.Doc 二进制状态，用于压缩增量和快速恢复 |
| High Water Mark | checkpoint 已覆盖的最高 `crdt_update.id` |
| Materialized HTML | 从 CRDT 状态转换并净化后写入 `document.content` 的可搜索正文 |
| LEGACY | 旧文档兼容模式，使用修订号和旧协作路径，不代表 OT |
| OT | Operational Transformation；本项目不实现、不计划实现 |
| Access Token | 短期 JWT，用于 API 和协作连接认证 |
| Refresh Token | 用于轮换新 Access Token 的高熵随机凭据，数据库只保存摘要 |
| Session | `user_session` 中的可撤销登录设备记录 |
| 文档所有者 | `document.owner_id` 指向的用户，天然拥有完整文档权限 |
| 文档 ADMIN | 只管理指定文档的协作者、分享和恢复点 |
| 系统 ADMIN | `user.system_role=ADMIN`，访问平台管理后台，不自动读取所有正文 |
| COMMENT 权限 | 可查看和批注但不能修改正文 |
| 物理删除 | 从数据库及关联存储彻底删除，区别于进入回收站的软删除 |
| 分片上传 | 把大文件拆成多个块上传，最终按顺序合并并校验 SHA-256 |
| DOCX ZIP 炸弹 | 利用高压缩率让小文件解压后占用巨大资源的恶意文档 |
| HTML 净化 | 按白名单移除脚本、事件属性和危险协议，降低 XSS 风险 |
| CSP | Content Security Policy，限制浏览器可执行脚本和加载资源来源 |
| DTO | Data Transfer Object，请求或跨层数据对象 |
| VO | View Object，对外响应视图对象 |
| RBAC | Role-Based Access Control；项目同时包含平台角色和资源权限 |
| WSS | 加密 WebSocket，生产环境协作连接必须使用 |
| RPO | 可接受的数据丢失时间范围，需要由备份策略确定 |
| RTO | 故障后恢复服务所需目标时间，需要由部署方确定 |
