# 云笺 DocFlow 故障排查与应急预案

## 1. 排查原则

1. 先保护数据，再重启或回滚。
2. 区分前端显示、Java 业务、CRDT、Redis、MySQL和文件存储。
3. 不通过关闭权限校验、开启循环依赖或删除表来临时“修复”。
4. 日志和截图脱敏，不传播 Token、密码和用户正文。

## 2. 服务无法启动

### Java 启动失败

- 检查 `java -version` 是否 JDK 17。
- 检查 MySQL 地址、账号、数据库和 23 张正式表。
- 检查端口 8080 是否占用。
- 出现 Bean 循环依赖时检查配置类和业务 Service 互相引用；不要开启 `allow-circular-references` 掩盖。
- 出现重复字段/索引时，说明升级脚本已经部分执行，先 `SHOW COLUMNS/SHOW INDEX` 再跳过已有语句。

### CRDT 启动失败

- 检查 `crdt_checkpoint`、`crdt_update`、`crdt_checkpoint_history`。
- 检查 MySQL 凭据、Java `DOCFLOW_API_URL` 和相同的 `CRDT_ADMIN_SECRET`。
- 本地可临时 `CRDT_REDIS_ENABLED=false`；生产多节点不可长期关闭。

### 前端启动失败

- 忽略 `node_modules` 源码排查，重新确认 Node 版本和 `npm install`。
- 检查 5173 端口；Vite 可能自动切换到 5174。
- 修改 `VITE_CRDT_URL` 后必须重启或重新构建。

## 3. 登录问题

| 现象 | 检查 |
| --- | --- |
| 登录后立即退出 | JWT 密钥是否一致、系统时间、`user_session` 是否创建 |
| 反复 401 | Access Token、Refresh 摘要、闲置超时、并发刷新 |
| 被封禁仍可访问 | JWT Filter 是否检查账号状态和 session，是否撤销全部设备 |
| 邮件验证码收不到 | MAIL_ENABLED、SMTP/TLS、发件人、超时和限流 |

不要在生产打开 `APP_VERIFICATION_DEBUG_CODE`。

## 4. “无协作权限”或 WebSocket 断开

按顺序检查：

1. `document.owner_id`、`is_deleted`、`collab_mode`。
2. Java `/docs/{id}/crdt/access` 使用同一个 JWT 是否返回 read/write。
3. 文档所有者是否被权限服务优先识别。
4. 前端是否在创建事务完成后才连接。
5. `VITE_CRDT_URL` 是否指向正在运行的 Hocuspocus。
6. CRDT 日志是 Java 403、数据库错误还是 Redis 错误。

禁止把所有登录用户都赋予访问权限。

## 5. 内容不同步或数据库不更新时间

- 确认两个用户连接相同 document name。
- 检查 `crdt_update` 是否新增、checkpoint 是否更新。
- 检查 Redis 节点名和连接状态。
- 检查协作服务快照回写 Java 是否成功。
- `document.updated_at` 只有执行物化 UPDATE 才变化，不能只依赖 `ON UPDATE`。
- 保留浏览器 IndexedDB 和服务端增量，未确认前不要清理。

## 6. checkpoint 恢复异常

1. 停止该文档继续写入或进入维护窗口。
2. 备份 `crdt_checkpoint`、history 和 update。
3. 检查目标 checkpoint 属于同一 docId。
4. 使用正式恢复接口，不直接手工改 BLOB。
5. 恢复后断开连接并让客户端重连。
6. 比较物化 HTML、checkpoint 高水位和剩余增量。

## 7. 分页和表格异常

- 页面横向无限扩展：检查双页容器是否固定两列并换行向下。
- 页间无灰色间隔：检查单页模式分页投影和遮罩层。
- 文字被盖住：检查缩放、页边距遮罩和 `content-visibility`。
- 表格被压成竖排：检查表格宽度是否错误继承双页容器宽度。
- 长表格消失：检查跨页 Decoration 是否插入合法的单元格内部。
- 滚动卡顿：确认只有编辑区一个垂直滚动容器，避免 ResizeObserver 写读循环。

## 8. 导入导出问题

- DOCX 损坏/超大：返回业务错误，不暴露 POI 堆栈。
- 图片导入后不显示：检查保存路径、URL 前缀和文件服务。
- PDF 中文乱码：配置 `EXPORT_FONT_PATH`。
- DOCX 外部图片未嵌入：当前只嵌入本项目可访问本地图片，不主动抓取互联网 URL。
- 导出内容旧：确认 CRDT 最新快照已物化，或导出接口提交当前 HTML。

## 9. 文件和磁盘

- 检查上传目录、临时分片、反馈截图和 DOCX 图片目录权限。
- 磁盘接近满时暂停大文件上传，先备份和清理超时临时文件。
- 数据库记录与文件不一致时先列出孤儿记录和孤儿文件，不直接批量删除。

## 10. 管理后台问题

- 普通用户看见入口：检查前端 `systemRole`，但后端拦截仍应拒绝。
- 管理员进入后台后左侧无响应：导航需先切回文档列表路由再加载 Store。
- 封禁未生效：检查 `user.status`、`user_session.revoked_at` 和 JWT Filter。
- 后台统计异常：检查对应表和 SQL，统计失败不应影响核心文档功能。

## 11. 应急等级

| 等级 | 示例 | 动作 |
| --- | --- | --- |
| SEV-1 | 数据丢失、任意越权、全站不可用 | 停止写入、保护证据、备份、回滚/恢复、负责人介入 |
| SEV-2 | 协作或登录大面积不可用 | 降级单节点、回滚服务、持续通报 |
| SEV-3 | 单模块故障、有替代路径 | 修复并回归，不阻断全部服务 |
| SEV-4 | 文案和轻微布局 | 进入普通迭代 |

## 12. 故障后复盘

记录时间线、影响范围、触发条件、根因、临时措施、永久修复、测试补充和负责人。涉及数据或安全事件时保留审计与备份，不在未授权渠道传播用户数据。
