# 云笺 DocFlow 安全设计与权限模型

> 生产部署的具体变量、兼容开关和上线核对步骤见《17-生产上线安全加固指南》；本文件描述应用内部的安全边界。

## 0. 本轮安全加固

- 登录失败计数同时绑定账号和客户端 IP；第三次失败后要求验证码，第五次失败后默认锁定账号登录 15 分钟。
- Redis 保存多节点共享的失败状态、验证码和限流计数；本地 Redis 故障时退回单机内存，生产应监控该降级日志。
- 支持 `HttpOnly + Secure + SameSite` Cookie，修改类请求使用 `XSRF-TOKEN` Cookie 与 `X-XSRF-TOKEN` 请求头进行 CSRF 校验。
- CRDT 连接使用两分钟有效的实时令牌，仍绑定当前登录设备会话。
- API 按普通请求、认证、上传和分享分别限流，并支持可信代理和 IP/CIDR 黑名单。
- Spring Security 输出 CSP、HSTS、X-Frame-Options、X-Content-Type-Options、Referrer-Policy 和 Permissions-Policy。
- 分享密码以 BCrypt 保存，旧明文数据在首次成功验证时自动迁移。
- 上传文件校验扩展名、文件头、大小和 ZIP 解压限制，并可接入 ClamAV。
- 生产可关闭匿名文件直链，公开分享只返回短期签名 URL；多节点生产建议使用私有对象存储。

## 1. 安全目标

- 防止未认证访问、横向越权和平台后台越权。
- 防止密码、验证码、令牌和密钥泄露。
- 防止 XSS、恶意文件、ZIP 炸弹、路径穿越和超大消息。
- 确保封禁、注销和设备撤销能够使现有会话失效。
- 保留关键管理操作的审计依据。

## 2. 认证与密码

- 密码使用 BCrypt，不可逆保存。
- Access Token 使用强随机 `JWT_SECRET` 签名，默认 30 分钟。
- JWT 包含 token ID，每次请求关联 `user_session` 检查。
- Refresh Token 使用安全随机数，数据库仅保存 SHA-256 摘要，并在每次刷新后轮换。
- 系统已支持 `Secure + HttpOnly + SameSite` Cookie；本地为兼容 Postman 默认关闭，生产必须通过外部配置开启，以减少 Web Storage 被 XSS 读取的风险。

## 3. 会话控制

- 闲置超时、绝对有效期、主动退出和设备撤销共同生效。
- 密码重置和管理员封禁撤销全部设备。
- 被封禁账号在 Access Token 和 Refresh Token 路径均重新检查状态。
- 前端并发 401 只发一个刷新请求，刷新失败清除全部本地凭据。

## 4. 授权模型

### 4.1 文档级权限

所有者优先，然后查询协作者：

```text
owner → full access
ADMIN → read + comment + write + manage
WRITE → read + comment + write
COMMENT → read + comment
READ → read only
none → deny
```

分享 token 是独立访问凭证，不提升登录用户协作者权限。已删除文档、恢复点和高风险操作有额外状态检查。

### 4.2 平台级权限

`user.system_role=ADMIN` 只允许平台管理 API。前端路由守卫不是安全边界，`/api/v1/admin/**` 必须经过后端管理员拦截器。平台管理员不会自动读取任意用户正文。

## 5. WebSocket 与 CRDT

- Hocuspocus 每次连接携带仅限协作鉴权接口使用的短期 JWT，并调用 Java 权限 API。
- 无读取权限不能订阅；无写权限的更新必须被拒绝。
- 单条更新限制 `CRDT_MAX_UPDATE_BYTES`。
- `updateId` 和唯一索引去重，避免重试扩大存储。
- CRDT 内部管理端口监听 127.0.0.1，使用共享密钥，不对浏览器开放。
- CRDT 正文快照通过独立内部密钥回写 Java，避免长时间连接依赖已经过期的用户令牌。

## 6. HTML 与脚本安全

- 前端 DOMPurify 用于即时显示保护。
- 后端 Jsoup 是不可绕过的最终净化边界。
- DOCX、Markdown、富文本保存、快照回写和分享展示都不能信任客户端 HTML。
- 链接协议、图片 URL、iframe、事件属性和 style 白名单必须受控。
- 生产设置 CSP，禁止内联脚本和不可信第三方资源。

## 7. 文件安全

- 校验扩展名、MIME、大小和必要文件头。
- 服务端生成存储名，禁止用户文件名参与路径拼接。
- DOCX 限制 ZIP 条目数、压缩率和解压总大小。
- 正文不保存大 Base64；图片和附件使用 URL。
- 多租户生产文件应使用私有对象存储、鉴权下载或短期签名 URL。

## 8. 邮件验证码

- SMTP 配置全部外部化。
- 验证码只保存 BCrypt 哈希，成功后立即写 `used_at`。
- 同邮箱、同 IP 设置冷却和每日上限。
- 真实发送失败不写入“已发送成功”状态。
- 生产禁止返回 debug code，日志不记录验证码和 SMTP 密码。

## 9. 分享安全

- 分享 token 使用高熵随机值，支持撤销和到期。
- 新建分享密码使用 BCrypt 保存；历史明文记录在首次成功验证后自动升级，接口响应不序列化密码字段。
- 分享页只返回允许展示的正文与元数据，不返回协作者、内部日志和恢复信息。

## 10. 管理后台安全

- 创建管理员采用受控 SQL 或由已有管理员提升，不开放公开“注册管理员”。
- 防止管理员封禁自己或取消自己的管理员身份。
- 封禁、角色调整、设备撤销、反馈处理、系统提示发送和模板维护记录审计日志。
- 系统提示发送只接受后端管理员拦截器认证的操作者；接收范围由服务端查库生成，不能由前端直接提交任意用户 ID 列表。
- 审计仅记录提示发送范围和人数，不复制消息正文；前端以文本插值显示提示，不执行管理员输入的 HTML。
- 后台列表限制数量；导出、批量操作和敏感字段应继续最小化。

## 11. 日志与隐私

禁止记录：密码、验证码、Refresh Token、完整 JWT、SMTP 密码、数据库密码和 CRDT 管理密钥。用户邮箱和 IP 在集中日志中应脱敏。生产应定义日志保留、访问审批和删除策略。

## 12. 威胁与措施

| 威胁 | 主要措施 |
| --- | --- |
| 凭据撞库 | BCrypt、账号/IP 失败计数、验证码、临时锁定和接口限流 |
| JWT 被盗 | 短期 Token、会话校验、设备撤销、HTTPS、CSP |
| Refresh 重放 | 摘要保存、行锁、一次轮换 |
| IDOR 越权 | Service 资源权限校验、所有者/协作者范围查询 |
| XSS | 前后端净化、CSP、受控 URL |
| 恶意上传 | 大小/扩展名/文件头/路径/ZIP 限制、可选 ClamAV 扫描 |
| 后台越权 | 前端守卫 + 后端拦截器 + 状态/角色复查 |
| CRDT 消息滥用 | 权限、大小限制、去重、连接监控 |

## 13. 上线前仍需完成的部署事项

- 开启安全 Cookie、HTTPS、ClamAV fail-closed 和匿名文件访问关闭开关。
- 按规模将本地文件迁移到私有对象存储，并使用短期签名 URL。
- 在测试环境验证 Nginx 限流和 WAF 规则误报，再切换为生产拦截模式。
- 运行已经配置的依赖审计、SAST、DAST 和密钥扫描，并处理高危结果。
- 由获得书面授权的专业人员完成真实渗透测试和修复复测。
- 制定隐私政策、数据删除和管理员审计保留制度。
