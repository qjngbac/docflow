# 云笺 DocFlow 项目验收与交付清单

## 1. 交付物

- [ ] Java 源码、父 POM 和正式数据库脚本。
- [ ] Vue 前端源码、静态资源和生产构建说明。
- [ ] CRDT 协作服务源码、协议和环境变量示例。
- [ ] 本目录全部工程文档。
- [ ] 无敏感信息的 `.env.example` 和 `application-example.yml`。
- [ ] 自动化测试和测试样本。

## 2. 环境验收

- [ ] JDK 17、Maven、Node、MySQL 和 Redis 版本满足要求。
- [ ] 全新 `schema.sql` 成功创建 23 张正式表。
- [ ] Java 8080、CRDT 1234、前端可访问。
- [ ] CRDT 1235 只监听本机/内网。
- [ ] SMTP、文件目录和生产密钥配置正确。

## 3. 功能验收

- [ ] 注册、登录、自动刷新、找回密码和设备管理。
- [ ] 文档/文件夹、搜索、收藏、标签、模板和回收站。
- [ ] Markdown、富文本、分页、表格、公式、脚注和文献。
- [ ] 两用户 CRDT 实时输入、光标、离线和重连。
- [ ] 四级权限、分享、批注、通知、版本和 checkpoint 恢复。
- [ ] DOC/DOCX/Markdown/TXT 导入与五种导出。
- [ ] 普通附件和分片上传。
- [ ] 用户反馈和管理员处理闭环。
- [ ] 用户封禁、角色、设备撤销、定向系统提示、模板、日志和系统状态。
- [ ] 全部/指定用户/注册时间范围发送正确，顶部提示可关闭且不会影响其他用户状态。

## 4. 数据验收

- [ ] 新文档 `owner_id`、`collab_mode=CRDT` 正确。
- [ ] 文档所有者无显式 permission 仍有完整权限。
- [ ] CRDT 增量、checkpoint、物化 HTML 和更新时间同步。
- [ ] checkpoint 失败不删除增量，历史恢复前保存当前状态。
- [ ] 删除、恢复和超期清理关联数据一致。

## 5. 安全验收

- [ ] 普通用户不能访问后台或他人资源。
- [ ] READ/COMMENT/WRITE/ADMIN 边界符合设计。
- [ ] 被封禁用户的全部会话失效。
- [ ] 生产不返回验证码，不使用默认密钥。
- [ ] HTML、上传、DOCX ZIP 和 CRDT 消息有限制。
- [ ] 日志无密码、验证码、Token 和密钥。
- [ ] 登录验证码、临时锁定、API 限流和 IP 黑名单通过异常流程测试。
- [ ] 安全 Cookie/CSRF、分享密码散列、短期文件签名和 ClamAV 按生产配置验收。
- [ ] 依赖、代码、密钥和 DAST 扫描完成，高危项已修复复测。
- [ ] 已完成书面授权的人工渗透测试；未完成时不得宣称通过安全认证。

## 6. 质量验收

- [ ] `mvn test` 通过。
- [ ] CRDT `npm test` 通过。
- [ ] 前端 `npm test`、`npm run build` 通过。
- [ ] Postman 主流程和异常权限流程通过。
- [ ] 两节点/Redis 生产架构至少完成一次真实冒烟。
- [ ] 无 P0/P1 缺陷，P2/P3 已登记。

## 7. 运维验收

- [ ] MySQL 和文件备份策略启用并完成恢复演练。
- [ ] 日志轮转、磁盘、数据库、Redis、HTTP 和 WebSocket 监控已配置。
- [ ] 发布、回滚和故障联系流程明确。
- [ ] Nginx HTTPS/WSS 和上传限制正确。
