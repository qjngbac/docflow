# 云笺 DocFlow 项目文档总览

## 1. 文档目的

本目录是云笺 DocFlow 的工程文档基线，内容以当前代码和数据库脚本为准，覆盖需求、设计、开发、测试、部署、运维和验收。项目包含三个可独立运行的服务：

- `docflow`：Spring Boot 业务服务，负责账号、权限、文档资产、导入导出和管理后台。
- `docflow-web`：Vue 3 前端，负责文档管理、富文本编辑、分页显示和用户交互。
- `docflow-collab`：Hocuspocus/Yjs CRDT 协作服务，负责实时同步、增量持久化和 checkpoint。

## 4. 当前基线

| 项目 | 当前基线 |
| --- | --- |
| 产品名称 | 云笺 DocFlow 在线多人协作文档平台 |
| Java | JDK 17、Spring Boot 3.2.5、MyBatis-Plus 3.5.6 |
| 前端 | Vue 3.4、Vite 8、Tiptap 3、Pinia |
| 协作 | Yjs 13、Hocuspocus 4、y-indexeddb |

| 认证 | 短期 Access Token、Refresh Token 轮换、可撤销设备会话 |
| 权限 | 文档 `READ/COMMENT/WRITE/ADMIN` + 系统 `USER/ADMIN` |
| 文档协作 | 新文档默认 CRDT；旧文档可保留 LEGACY 兼容路径；不实现 OT |

## 5. 文档维护规则

- 代码、SQL 与文档冲突时，以已验证的运行代码和正式迁移脚本为事实来源，并及时修正文档。
- 新增接口时同步更新 `05-API接口设计说明.md` 和接口测试手册。
- 新增表或字段时同步更新 `04-数据库设计与数据字典.md`，并提供可重复执行的升级脚本。
- 修改认证、权限、上传或协作流程时同步更新安全设计、测试计划和故障预案。
- 不在文档中记录真实密码、邮箱授权码、JWT 密钥、数据库密码或生产地址。
- 重要版本发布后更新 `14-版本变更记录.md`，记录兼容性、数据库迁移和回滚要求。

## 6. 已知边界

- 当前实时分页是基于单一 ProseMirror/Yjs 文档的页面投影，不等同于完整 Word 排版引擎。
- DOC/DOCX、PDF 和 Markdown 转换覆盖常用结构，不承诺复杂 Word 特性或任意自定义 HTML 完全无损。
- 本地文件存储适合开发和单机部署；多节点生产环境应迁移到对象存储并补充访问控制。
- Redis 用于跨节点实时广播，不是 CRDT 最终数据源；MySQL checkpoint 与增量才是恢复依据。
