# 云笺 DocFlow 软件需求规格说明书

## 1. 产品说明

云笺是一套在线多人协作文档平台，提供账号安全、文档组织、富文本编辑、CRDT 实时协作、审阅、版本、附件、导入导出、问题反馈和系统管理能力。

## 2. 用户与使用场景

| 用户 | 典型场景 |
| --- | --- |
| 个人用户 | 写学习笔记、整理资料、导入和导出文档 |
| 团队成员 | 邀请伙伴实时编辑、批注和审阅 |
| 文档所有者 | 管理协作者、分享链接、版本和恢复点 |
| 系统管理员 | 处理用户反馈、管理账号、模板和运行状态 |

## 3. 功能需求

### FR-01 账号注册与登录

- 用户可使用唯一用户名、邮箱和密码注册。
- 用户可登录、退出、保持登录、修改密码和找回密码。
- 登录过期后前端自动使用 Refresh Token 续期；失败则返回登录页。
- 被封禁用户登录时显示明确原因，不能继续使用旧设备会话。

**验收：** 正确凭据登录成功；错误密码、禁用账号和过期会话均被拒绝；Refresh Token 一次轮换后旧值失效。

### FR-02 个人资料与设备

- 用户可修改昵称、邮箱、头像和密码。
- 邮箱修改和密码找回使用一次性验证码。
- 用户可查看设备、退出指定设备或退出其他设备。

**验收：** 资料持久化；验证码过期或重复使用失败；被撤销设备的后续请求返回未认证。

### FR-03 文档与文件夹

- 支持文档创建、读取、重命名、复制、移动、删除、恢复和彻底删除。
- 支持树形文件夹、置顶、收藏、标签、分类、最近编辑和批量操作。
- 支持空白、模板和本地文件三种创建路径，并可选择封面。
- 回收站显示剩余保留时间，并自动清理超期内容。

**验收：** 用户只能管理自己拥有或有权访问的资源；删除可恢复；超期清理不影响正常文档。

### FR-04 全局搜索

- `Ctrl + K` 打开搜索。
- 搜索有权访问的文档、自己的文件夹和启用的协作用户。
- 文档与文件夹可直接跳转，用户结果可用于添加协作者。

**验收：** 无权限文档和其他用户私有文件夹不出现在结果中。

### FR-05 富文本编辑

- 支持标题、段落、粗体、斜体、下划线、删除线、列表、任务列表、引用、代码、链接、图片、表格和分割线。
- 支持字体、字号、颜色、对齐、行距、格式刷、特殊字符、脚注、文献引用、目录和搜索替换。
- 支持表格增删行列、合并拆分、宽高调整、排序、多单元格选择和复制粘贴。
- 支持结构化公式、常用符号、矩阵、多行、化学式、编号和交叉引用。

**验收：** 常用格式可插入、修改和再次打开；危险 HTML 被净化；无法无损转换的格式按文档说明降级。

### FR-06 页面与分页

- 支持 A4/Letter、页边距、页眉、页脚、页码和分页符。
- 支持单页和双页显示，双页按两列向下排列，奇数尾页居中。
- 支持 `Ctrl + 鼠标滚轮`缩放；单页默认 100%，双页默认 80%。
- 普通段落和常规表格可以跨页，内容不得显示在页边距区域。

**验收：** 长文档持续向下分页；滚动条可拖动且无循环跳动；切换模式不改变正文。

### FR-07 CRDT 实时协作

- 新文档默认使用 Yjs CRDT。
- 显示在线用户、实时光标和选区。
- 支持离线编辑、待同步数量、重连和最终一致。
- 服务端保存增量和多代 checkpoint，支持指定恢复点回滚。

**验收：** 两用户并发编辑后内容一致；重复和乱序更新不重复应用；重启后可恢复。

### FR-08 权限与分享

- 文档权限包括 READ、COMMENT、WRITE 和 ADMIN。
- 所有者即使没有权限表记录也拥有完整权限。
- 支持带可选密码和失效时间的分享链接。

**验收：** COMMENT 只能批注，WRITE 不能管理协作者，ADMIN 可以管理；无权用户 HTTP 与 WebSocket 均被拒绝。

### FR-09 批注、通知和审阅

- 支持选区批注、回复、@用户、解决、筛选和批量解决。
- 支持基础修改痕迹、接受/拒绝和段落修改者信息。
- 站内通知支持未读计数、按类型筛选、单条已读和全部已读。
- 管理员系统提示显示在用户页面上方，用户可关闭，关闭后不再重复显示该条提示。

**验收：** 批注位置可定位；处理反馈或 @提及时目标用户收到通知；只读用户不能创建批注。

### FR-10 版本与恢复

- 支持手动保存版本、命名、说明、历史列表、详情、左右差异对比和回滚。
- 文档管理员可查看、创建和恢复 CRDT checkpoint。

**验收：** 回滚前保留当前状态；失败不删除现有增量；无管理权限用户不能执行恢复。

### FR-11 文件、导入与导出

- 支持普通附件和大附件分片上传、下载和删除。
- 支持 Markdown、TXT、DOC、DOCX 导入。
- 支持 DOCX、PDF、离线 HTML、Markdown 和 TXT 导出。
- DOCX 内嵌位图转为文件 URL，正文不保存大 Base64。

**验收：** 正常文件可处理；空、损坏、超大和 ZIP 炸弹文档返回明确错误；导出文件可打开。

### FR-12 问题反馈

- 用户可选择问题类型、填写描述、关联当前文档并上传最多 6 张图片。
- 用户可查看自己提交的反馈和管理员回复。
- 管理员可筛选状态/类型、查看截图、更新状态和回复。

**验收：** 用户不能读取他人反馈；关联文档前校验读取权限；处理后发送站内通知。

### FR-13 系统管理

- 管理员可查看总览、用户、反馈、系统模板、操作日志和系统状态。
- 管理员可封禁/解封用户、调整系统角色和撤销全部设备。
- 管理员可向全部用户、某个用户名或指定注册时间范围内的用户发送系统提示。
- 管理员不能封禁自己或取消自己的管理员身份。

**验收：** 普通用户前后端均不能进入后台；封禁立即使现有会话失效；系统提示只到达所选用户且可关闭；管理动作可审计。

## 4. 非功能需求

### NFR-01 安全

- 密码使用 BCrypt；验证码只保存哈希；Refresh Token 只保存 SHA-256 摘要。
- 所有资源操作在服务端鉴权；生产使用 HTTPS/WSS。
- 上传限制大小、扩展名、MIME、路径和 DOCX 解压规模。
- HTML 在前后端净化；日志不记录凭据和验证码。

### NFR-02 可靠性

- CRDT 更新具有幂等去重和事务 checkpoint。
- 浏览器离线状态、MySQL 恢复状态和 Redis 广播职责分离。
- 关键数据可备份，恢复过程先保护当前状态。

### NFR-03 易用性

- 页面操作和错误提示使用普通用户可理解的中文。
- 危险操作使用居中确认窗口，不使用浏览器原生 `alert/confirm`。
- 主要功能提供图标、标题提示和响应式布局。

### NFR-04 可维护性

- 三个服务职责清晰，配置外部化。
- 数据库升级有版本脚本；接口、表结构和文档同步维护。
- 核心服务和转换工具有自动化测试。

## 5. 数据与隐私要求

- 用户只能访问自己的资料、设备和反馈。
- 文档访问取决于所有者、协作者或分享凭证。
- 管理员不应通过平台角色默认读取所有私有正文。
- 删除账号、数据导出、隐私协议和合规保留策略当前未形成完整产品流程，生产商用前必须补齐。

## 6. 兼容性

- 桌面端优先支持当前版本 Chrome、Edge 和 Firefox。
- 移动端提供基本浏览和操作，但复杂分页与表格编辑以桌面体验为主。
- Java 运行环境为 JDK 17；数据库为 MySQL 8；Node.js 建议 18+。

## 7. 需求优先级

| 级别 | 范围 |
| --- | --- |
| P0 | 登录、文档 CRUD、权限、CRDT 同步、持久化、基本编辑和恢复 |
| P1 | 批注、版本、导入导出、附件、设备管理、回收站、搜索 |
| P2 | 分页增强、公式、文献、反馈、管理后台和高级表格 |
| 后续 | 对象存储、全文搜索引擎、可观测性、移动端深度适配、合规流程 |
